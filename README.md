# 循练 · LOOP（Android 1.6.5）

离线训练计划、运动计数与计时工具，支持 Android 8.0 及以上。本地开发签名，供个人侧载使用，未上架应用商店。

## 安装

把 `LoopTraining-1.6.5.apk` 传到手机打开安装；需要时允许文件管理器安装未知应用。由同一开发密钥签名的新版可以覆盖安装并保留数据。不要先卸载旧版。

## 训练计划

- 内置 12 周俯卧撑计划（33 个训练日，含可选轻训练），以及仰卧起坐、深蹲示例。
- 可创建多天计划，任意一天开始；完成显示绿色对勾，未完成显示灰色圆点。同一天可反复练习，每次独立记入统计。
- 进入计划详情时，自动定位最近一次完整完成日程的下一条；若最近完成的是最后一条，则定位最后一条供重练。部分完成的记录不会改变完成对勾或推荐位置。
- 卡片采用紧凑布局，单动作日程只显示各组次数。标题隐藏“可选”和“开练前/开始前编辑目标”等附注。起始日期可选，设定后仅用于排期提示，不限制实际训练日期。
- 内置俯卧撑建议周一 A、周三可选 C、周六 B；减量周两次。测试日目标开练前自行修改；12 周不保证达到连续 100 个。

## 计数、休息与结束

1. 点击训练日“开始”，查看每组目标及对应休息时间。目标用滚轮 picker 选择，也可切到手动输入；计时目标按时、分、秒选择。
2. 俯卧撑默认使用距离传感器：手机平放，脸靠近屏幕上方听筒附近加一次，无需接触；抬起稳定至少 180ms 后才能再次靠近计数，两次至少间隔 450ms。启动时已遮住传感器不计数，先抬起。全屏触屏计数同时可用，鼻尖一接触就计数（无需等松开），350ms 防重复；触屏和距离感应同时开启，同次靠近触屏去重；可单独关闭距离感应。无传感器或启动失败自动使用触屏。暂停、休息及后台停止感应，继续或下一组自动恢复。安卓隐藏系统栏，无减一按钮。其他计次运动保留加减。
3. 每次实际加减数字发声。无文字的铃铛图标开关控制计数音、目标提示音和破纪录声音，带斜杠表示静音。计次按钮无按下背景色变化；裂屏效果采用低亮度；开关设置自动保存；声音使用手机媒体音量。
4. 前面的组达到目标后自动进入休息，无需再点完成；也可提前按实际完成量结束本组。休息时可加 15 秒、30 秒、1 分钟，也可立即开始下一组。倒计时结束自动开始下一组。
5. 达到目标只提示，不自动结束。最后一组可继续计数和计时；点击“结束并保存”并确认后才停止和保存。
6. 也可从顶部“结束”保存部分完成的实际训练量；未完整完成的日程不会打勾。可保留进度、放弃本次。
7. 手动暂停或退出应用会暂停计时并保存进度，重新进入后点击继续。独立计时器也采用此规则，不提供后台闹钟通知。

## 自由训练

底部“自由训练”先显示入口，按单次运动、计数器、计时器排序；进入各自设置页后再选择参数。次数和时间目标均支持滚轮 picker 和手动输入。功能包含：

- 手动计数器：圆圈所在整个长方形区域均可加一，另有加大的＋1按钮；可设初始数字，自由加减，带用时，可暂停、重置、保留进度；不计入运动统计。
- 计时器：正计时或倒计时。点击大号时间可暂停，再点继续，暂停时显示“已暂停”；单次计时运动与组间休息倒计时也支持点击时间暂停/继续。倒计时归零后提示，并继续显示超时时间，手动关闭才结束；不计入运动统计。
- 单次运动：俯卧撑、仰卧起坐、深蹲、平板支撑及自定义动作；可设次数或秒数目标。平板支撑默认计时，达到目标可继续，手动结束后记入统计。

同一时间支持一场活动；若已有未完成的训练或工具，会提示先继续或结束当前活动。

## 预计用时与日程操作

日期后显示预计总分钟数，包含各组动作时间和计划组间休息。每个动作采用近期最多 30 组的每次动作耗时中位数；没有足够有效历史时，按每次 3 秒估算。计时动作直接使用目标秒数。旧版只有整场用时而没有每组动作时间的记录不会被拿来推算速度，以免把休息算两次。预计用时不含热身，最后一组超额训练或临时加休息会使实际时间更长。

点击日程前的编号可选择：

- 重置为未完成：只重置该日完成标记，历史记录、统计、个人纪录都保留；再次完成会重新打勾。
- 从当前开始顺延：用天数 picker 选择 1～365 天，当前及后续日程的计划日期一起延后。支持多次累计顺延；以前的实际训练日期不变。须先设置计划起始日期。

重置和顺延信息会包含在完整 JSON 备份中。复制计划文本仅分享训练内容，不复制完成状态与排期调整。

## 单组纪录与特效

按“动作名称 + 计次/计时方式”分别保存最高单组次数或最长单组时间。升级会从以前保存的训练中整理已有纪录。首次运动建立基准；以后每次超过历史最高值都会播放碎玻璃音效并触发低亮度屏幕裂纹特效，继续超过则再次触发。关闭声音仍保留视觉特效。

在“自由训练 → 我的单组纪录”中可按动作重置纪录，也可在没有纪录时建立基准。计次纪录默认重置为 10 次；计时纪录默认 10 秒，可通过 picker 或手动输入调整。重置不删除历史训练与统计，重启后不会被重置前的旧成绩覆盖；之后超过新基准继续触发庆祝。

纪录在训练过程中实时保存，放弃一场训练不会抹去已实际达到的新纪录。手动减数不会下调已经达到的历史纪录。计时运动的每秒增长也提供声音反馈，可通过声音开关关闭。

## 统计与数据

支持按天、周、月、年选择周期与日期；周一为每周首日，按完成当天手机本地日期归属。重复训练分别计入。计次和计时分开汇总，平板支撑秒数不会算成动作次数。训练用时包含组间休息，不含暂停。

所有数据保存在手机本地，无账户、联网、相机或麦克风权限。未完成活动自动保存。完整备份包括计划、已保存训练记录、个人纪录和声音设置，不含未结束活动。

“数据与导入 → 导出备份”复制 JSON，请存到自己的笔记或文件。恢复前校验并展示数量，确认后替换本机数据。卸载或清除应用数据会清除本机记录，系统云备份已关闭，操作前请手动备份。

## 计划文本格式

```text
计划：我的全身训练

第1天：基础训练
俯卧撑 | 25,25,25,25,25 | 120,120,150,180
深蹲 | 15,15,15,15 | 90

第2天：核心训练
仰卧起坐 | 12,12,12,12 | 90
```

每个动作一行：`动作名称 | 每组次数 | 休息秒数`。次数用逗号分隔；休息填一个统一值，或按组间填写（组数减一项）。一天可写多个动作，动作间采用前一个动作最后可用休息值。最多 1092 个训练日程，每天最多 20 个动作，每个动作最多 30 组。空行及以 `#` 开头的注释忽略。

在新建/导入中粘贴文本，检查预览后保存；现有计划可以复制文本分享。编辑为新计划会保留原计划和记录。

## 感应计数（实验）

安卓安装版通过加速度计、可用时结合重力传感器，估算手机随身体移动的垂直运动周期。手机需安全固定并随身体运动；静放地面无法通过重力感应识别俯卧撑。开启后先保持起始姿势约 2 秒。

效果受机型、动作和放置方式影响，未在用户真机校准，不判断动作质量。建议先用点击计数。暂停、休息、离开应用后停止感应，继续时需手动重新开启。

## 源码与构建

Java Activity 提供私有存储、剪贴板、原生 SoundPool、全屏系统栏控制、触觉与传感器；HTML/CSS/JavaScript 实现界面和训练状态。音效为本地合成 WAV，全部随 APK 打包。WebView 仅加载限定本地模块。

Android Studio 可打开本目录：Gradle 插件 8.12.1、compile/target SDK 36、min SDK 26、Java 17，无第三方运行依赖。首次 Gradle 同步可能需网络。

也可运行 `./build.sh`，需要 SDK platform 36、build-tools 36.0.0、JDK 17。默认使用 macOS 路径；其他环境设置 `ANDROID_SDK_ROOT` 和 `ANDROID_JAVA_HOME`。APK 输出到项目父目录。签名密钥在 `.build/development.jks`，源码压缩包不含私钥；自行构建若更换密钥，需先备份，再卸载旧版安装新版并恢复。

## 1.3.0 靠近计数

使用 Android TYPE_PROXIMITY，无相机或额外权限。硬件通常只报告近/远，距离阈值受手机硬件影响，应用不能把整个屏幕变成悬空感应区。当前已确认 HBP-AL00 有距离传感器；实际鼻尖位置和识别效果需在手机上试用。触屏模式保留为备用。

深蹲课程示例见 `examples/squats-40-to-100.txt`：每周A/B两次，C轻训练可跳过；每4周减量与测试。完成困难时重复本周，12周不保证达到100次。

距离计数验证：`npm run test:proximity`；纯 Java 防抖用例为 `tests/ProximityCounterTest.java`（与 `ProximityCounter.java` 一起编译后运行）。覆盖启动遮挡、近处停留、远近循环、快速抖动、暂停恢复、触屏去重、组间切换与感应不可用回退。

## 1.3.1 运动感应默认设置

深蹲、仰卧起坐的计次训练（课程和单次运动）默认开启运动感应；暂停、休息、返回其他页面及后台停止感应，继续和下一组自动恢复。手动关闭后本次训练保持关闭，新开一次训练仍默认开启。计时动作、独立计数器与计时器不自动开启。无加速度计时回退点击。手机必须随身体运动，开始/恢复时保持起始姿势2秒校准。

## 1.6.0 同时感应和触屏

俯卧撑默认同时支持距离感应和触屏，旧版触屏模式偏好升级为默认双输入；仍可手动关闭距离感应。深蹲、仰卧起坐及手动开启运动感应的动作也同时支持点击。感应开启时，所有来源共用1000ms防重复窗口；距离保持近状态时一次靠近最多计一次，抬起后重新允许。独立手动计数器不受此限制。该规则用于减少同次动作双算，过快切换输入方式的动作仍可能被合并。

## 1.6.0 动作库与目标生成

- 动作库加入臀桥、侧平板、靠墙静蹲、保加利亚蹲、提踵和飞鸟式；飞鸟式在本应用中特指鸟狗式（跪姿对侧手脚伸展），附说明以区别哑铃飞鸟；未加入弓步蹲。
- 新建计划 → 按当前能力和目标生成：选择动作、当前连续完成量、目标、1～52周、每周1～3次、每次4～5组/轮、开始日期。数值支持picker及手动输入，预览日期、目标、组间休息、预计耗时后保存。
- 普通计次、静态计时、单侧动作分别编排；单侧按较弱侧输入，每轮左右各一组，分别记录。第4/8等周减量，周期最后一次复测；每周1/2/3次分别使用起始日偏移0 / 0,3 / 0,2,4，留恢复时间。
- 生成使用启发式规则：周参考能力上限为 `min(目标, 当前 × (1+项目增长率)^周索引)`。增长率依项目取4%～8%；常规组按参考能力45%～55%，轻训练再乘75%，减量周乘65%。长组第一组按70%；最终复测按受控参考能力安排，不强行跳到尚未接近的目标。周数和百分比不能预测或保证个人进步，应按完成情况降量、重复或延长周期。
- 这些规则为应用初始编排，不是研究验证过的个体处方。一般训练频率和逐步调整的参考：[ACSM 2026](https://acsm.org/resistance-training-guidelines-update-2026/)、[ACSM progression stand](https://pubmed.ncbi.nlm.nih.gov/19204579/)。动作定义：[NASM Bird Dog](https://www.nasm.org/resource-center/exercise-library/bird-dog)。
- 新动作默认点击或计时，未经真机校准不自动开启运动感应；深蹲、仰卧起坐保持默认感应。所有感应与点击仍共用1秒去重。
- 文本格式兼容旧版；计时行可加第四列 `| 秒`，训练日标题末尾 `@+7天` 表示相对起始日期的偏移。完整备份保留生成参数和说明，普通文本保留单位与相对排期。
- 测试：`node tests/generator.test.cjs`、`npm run test:generator`。

## 1.4.1 计划列表与定位

计划卡片采用紧凑布局，仅保留标题、进度条、完成数/总数和下次运动日期；未排期时显示待排期，全部完成时显示可再次训练。长按约450ms在当前页进入操作状态，可继续上下拖动排序；松手后每个计划直接显示暂停/恢复和删除。点击完成或系统返回退出操作状态。暂停计划置灰并排在列表末尾，同状态内可排序。顺序随完整备份保存。

进入详情定位到下一训练前的两条已完成日程，下一日程继续高亮。详情仅保留固定的返回按钮和计划标题，下方仅日程列表滚动，不再展示“训练日程”标题和上方附加内容。显示标题移除独立A/B/C标签，原始标题和排期数据保留。测试 `npm run test:plans` 覆盖鼠标和真实触屏长按、滚动取消、持久保存以及定位和卡片布局。

## 1.6.0 本组计时与动作统计

计次训练的本组时间在计数区域下方独立显示，36px等宽数字，并显示运动中/已暂停。统计新增动作筛选（左右侧按同一动作合并）；天、周、月、年、次数、计时分布和训练列表均按筛选范围展示。

时长卡片并排展示运动时长（各组duration合计，不含休息及暂停）和整次训练总时长（含休息）；新日志额外保存activeDuration。混合训练筛选后，总时长显示包含该动作的整次训练，并在卡片说明，运动时长只累计所选动作。旧计次记录若没有每组duration，显示缺失提示，不按总时长推算或默认为已运动0秒；旧计时记录可用记录秒数补齐。日志和完整备份保留原始数据。

验证 `npm run test:stats`：混合动作筛选、左右合并、不同时间周期、时长缺失处理、暂停冻结和组间休息排除。

## 1.6.0 一屏练习页

首页训练积累卡片可点击进入训练统计（清除动作筛选并定位今天）。练习页移除顶部操作栏、重复组数、英文标语和达标休息说明；底部同一行显示暂停、完成本组/结束并保存、结束，主按钮更大，次按钮更小。保留本组大号时间、感应控制、计数和休息倒计时，休息页同样支持暂停、加时和立即下一组。

## 1.6.0 默认目标创建与双列指标

## 1.6.0 每日文案、计划管理与提醒

首页顶部展示日期和星期，主文案从100句本地文案中按天轮换。今日有排期的计划图标显示圆点，点击计划后当天圆点消失，重启后保持，下次排期日重新显示。暂停计划不显示圆点。暂停和恢复保留完成记录与排期日期，不自动顺延。

统计日期选择及周期标题旁均提供“今天”。练习页进一步收紧空白；暂停时完成本组会直接进入运行中的休息倒计时。非输入区域禁用文本选择光标，输入框和计划文本编辑保留编辑能力。日程编号的重置与顺延功能保留，未设置起始日期时可在操作中选择日期。
