# 循练 · LOOP（Android 1.2.1）

离线训练计划、运动计数与计时工具，支持 Android 8.0 及以上。本地开发签名，供个人侧载使用，未上架应用商店。

## 安装

把 `LoopTraining-1.2.1.apk` 传到手机打开安装；需要时允许文件管理器安装未知应用。由同一开发密钥签名的新版可以覆盖安装并保留数据。不要先卸载旧版。

## 训练计划

- 内置 12 周俯卧撑计划（33 个训练日，含可选轻训练），以及仰卧起坐、深蹲示例。
- 可创建多天计划，任意一天开始；完成显示绿色对勾，未完成显示灰色圆点。同一天可反复练习，每次独立记入统计。
- 进入计划详情时，自动定位最近一次完整完成日程的下一条；若最近完成的是最后一条，则定位最后一条供重练。部分完成的记录不会改变完成对勾或推荐位置。
- 卡片采用紧凑布局，单动作日程只显示各组次数。标题隐藏“可选”和“开练前/开始前编辑目标”等附注。起始日期可选，设定后仅用于排期提示，不限制实际训练日期。
- 内置俯卧撑建议周一 A、周三可选 C、周六 B；减量周两次。测试日目标开练前自行修改；12 周不保证达到连续 100 个。

## 计数、休息与结束

1. 点击训练日“开始”，查看每组目标及对应休息时间。目标用滚轮 picker 选择，也可切到手动输入；计时目标按时、分、秒选择。
2. 俯卧撑采用全屏点击：中央圆盘、标题和空白区域均可加一次，控制按钮不计数；安卓会隐藏系统栏，方便鼻尖点击。没有减一按钮。其他计次运动保留加减。
3. 每次实际加减数字发声。无文字的铃铛图标开关控制计数音、目标提示音和破纪录声音，带斜杠表示静音。计次按钮无按下背景色变化；裂屏效果采用低亮度；开关设置自动保存；声音使用手机媒体音量。
4. 前面的组达到目标后自动进入休息，无需再点完成；也可提前按实际完成量结束本组。休息时可加 15 秒、30 秒、1 分钟，也可立即开始下一组。倒计时结束自动开始下一组。
5. 达到目标只提示，不自动结束。最后一组可继续计数和计时；点击“结束并保存”并确认后才停止和保存。
6. 也可从顶部“结束”保存部分完成的实际训练量；未完整完成的日程不会打勾。可保留进度、放弃本次。
7. 手动暂停或退出应用会暂停计时并保存进度，重新进入后点击继续。独立计时器也采用此规则，不提供后台闹钟通知。

## 自由训练

底部“自由训练”先显示入口，按单次运动、计数器、计时器排序；进入各自设置页后再选择参数。次数和时间目标均支持滚轮 picker 和手动输入。功能包含：

- 手动计数器：可设初始数字，自由加减，带用时，可暂停、重置、保留进度；不计入运动统计。
- 计时器：正计时或倒计时。点击大号时间可暂停，再点继续，暂停时显示“已暂停”；单次计时运动与组间休息倒计时也支持点击时间暂停/继续。倒计时归零后提示，并继续显示超时时间，手动关闭才结束；不计入运动统计。
- 单次运动：俯卧撑、仰卧起坐、深蹲、平板支撑及自定义动作；可设次数或秒数目标。平板支撑默认计时，达到目标可继续，手动结束后记入统计。

同一时间支持一场活动；若已有未完成的训练或工具，会提示先继续或结束当前活动。

## 预计用时与日程操作

日期后显示预计总分钟数，包含各组动作时间和计划组间休息。每个动作采用近期最多 30 组的每次动作耗时中位数；没有足够有效历史时，按每次 3 秒估算。计时动作直接使用目标秒数。旧版只有整场用时而没有每组动作时间的记录不会被拿来推算速度，以免把休息算两次。预计用时不含热身，最后一组超额训练或临时加休息会使实际时间更长。

点击日程前的编号可选择：

- 重置为未完成：只重置该日完成标记，历史记录、统计、个人纪录都保留；再次完成会重新打勾。
- 从当前开始顺延：用天数 picker 选择 1～365 天，当前及后续日程的计划日期一起延后。支持多次累计顺延；以前的实际训练日期不变。须先设置计划起始日期。

重置和顺延信息会包含在完整 JSON 备份中。复制计划文本仅分享训练内容，不复制完成状态与排期调整。

## 单组纪录与特效

按“动作名称 + 计次/计时方式”分别保存最高单组次数或最长单组时间。升级会从以前保存的训练中整理已有纪录。首次运动建立基准；以后每次超过历史最高值都会播放碎玻璃音效并触发低亮度屏幕裂纹特效，继续超过则再次触发。关闭声音仍保留视觉特效。

在“自由训练 → 我的单组纪录”中可按动作重置纪录，也可在没有纪录时建立基准。计次纪录默认重置为 10 次；计时纪录默认 10 秒，可通过 picker 或手动输入调整。重置不删除历史训练与统计，重启后不会被重置前的旧成绩覆盖；之后超过新基准继续触发庆祝。

纪录在训练过程中实时保存，放弃一场训练不会抹去已实际达到的新纪录。手动减数不会下调已经达到的历史纪录。计时运动的每秒增长也提供声音反馈，可通过声音开关关闭。

## 统计与数据

支持按天、周、月、年选择周期与日期；周一为每周首日，按完成当天手机本地日期归属。重复训练分别计入。计次和计时分开汇总，平板支撑秒数不会算成动作次数。训练用时包含组间休息，不含暂停。

所有数据保存在手机本地，无账户、联网、相机或麦克风权限。未完成活动自动保存。完整备份包括计划、已保存训练记录、个人纪录和声音设置，不含未结束活动。

“数据与导入 → 导出备份”复制 JSON，请存到自己的笔记或文件。恢复前校验并展示数量，确认后替换本机数据。卸载或清除应用数据会清除本机记录，系统云备份已关闭，操作前请手动备份。

## 计划文本格式

```text
计划：我的全身训练

第1天：基础训练
俯卧撑 | 25,25,25,25,25 | 120,120,150,180
深蹲 | 15,15,15,15 | 90

第2天：核心训练
仰卧起坐 | 12,12,12,12 | 90
```

每个动作一行：`动作名称 | 每组次数 | 休息秒数`。次数用逗号分隔；休息填一个统一值，或按组间填写（组数减一项）。一天可写多个动作，动作间采用前一个动作最后可用休息值。最多 366 天，每天最多 20 个动作，每个动作最多 30 组。空行及以 `#` 开头的注释忽略。

在新建/导入中粘贴文本，检查预览后保存；现有计划可以复制文本分享。编辑为新计划会保留原计划和记录。

## 感应计数（实验）

安卓安装版通过加速度计、可用时结合重力传感器，估算手机随身体移动的垂直运动周期。手机需安全固定并随身体运动；静放地面无法通过重力感应识别俯卧撑。开启后先保持起始姿势约 2 秒。

效果受机型、动作和放置方式影响，未在用户真机校准，不判断动作质量。建议先用点击计数。暂停、休息、离开应用后停止感应，继续时需手动重新开启。

## 源码与构建

Java Activity 提供私有存储、剪贴板、原生 SoundPool、全屏系统栏控制、触觉与传感器；HTML/CSS/JavaScript 实现界面和训练状态。音效为本地合成 WAV，全部随 APK 打包。WebView 仅加载限定本地模块。

Android Studio 可打开本目录：Gradle 插件 8.12.1、compile/target SDK 36、min SDK 26、Java 17，无第三方运行依赖。首次 Gradle 同步可能需网络。

也可运行 `./build.sh`，需要 SDK platform 36、build-tools 36.0.0、JDK 17。默认使用 macOS 路径；其他环境设置 `ANDROID_SDK_ROOT` 和 `ANDROID_JAVA_HOME`。APK 输出到项目父目录。签名密钥在 `.build/development.jks`，源码压缩包不含私钥；自行构建若更换密钥，需先备份，再卸载旧版安装新版并恢复。

## 验证

- `npm test`：导入格式、备份、统计周期、次数和秒数分离、最近完成日程定位、重置、顺延与预计耗时。
- `npm install` 后运行 `npm run test:ui`：导入、暂停恢复、多组训练、重复训练、统计、备份恢复与持久化。默认本机 Chrome，其他路径设置 `CHROME_PATH`。
- `npm run test:upgrade`：目标 picker 与手动输入、非最后组自动休息、最后组继续、休息恢复与加时、重置保留历史、顺延及重启恢复、自由训练入口、计时/计次 picker、统计单位。
- `tests/MotionCounterTest.java`：合成数据的噪声拒绝、防抖、完整周期、超时，不代表真机识别率。
- 在 Android 16 独立模拟器通过原生集成验证：四种声音资源加载和调用、全屏点击、私有存储、休息加时、最终确认、完成勾选、统计、独立计时器和进度保存；1.2 另验证安卓原生滚轮 picker、手动输入、非最后组自动休息、最后组继续、预计耗时与重置。
